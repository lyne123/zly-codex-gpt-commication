# RTL 与工程审查

## 范围与基线

活动源码为本工程 `fpga_tdc_v3_cal_rtl/` 下五份 Verilog。完整阅读后，与相邻 `fpga_tdc_v3/fpga_tdc_v3_rtl/` 的五文件 SHA256 逐项核对，全部相同。本工程没有 XPR/XDC/IP；所需 XPR、XDC、四个 XCI 只读复制到 `inputs/`，实际构建使用独立工程。原始五文件在 `baseline/rtl/`，哈希在 `baseline/sha256.json`；本目录没有 Git 仓库，采用可恢复快照。

器件为 xc7k325tffg900-2。时钟 IP 输入 100 MHz，输出 500 MHz 的 0/90/180/270° 与 100 MHz。顶层 COARSE_W=10，回卷为 2,048,000 ps；locate/merge 单独实例的默认 COARSE_W=8。CARRY_NUM=16、64 taps、TAP_PS=10 与请求一致。

## 信号链与对齐

PWM → 同源三级 LUT1 恒等分发树 → 四条独立 CARRY4（16 级）→ 每相 thermo_q → 分组计1树与极性流水 → 270→180→90→0°汇聚；0°少一级，以表达下一周期0°。另一路 PWM 直达0°两级同步与辅助检测，未经过 LUT 分发。联合门控使用辅助延迟 bit5|bit4。分发树、采样与 CARRY4 级联本次保持原样。

源码注释存在陈旧值：细测顶层实际 MAX_VALID_TAP=60、MIN_VALID_TAP=5；子模块默认55/10被上层覆盖；极性还需要首尾各4 tap的3票多数判决，不能把注释的范围直接当作实际覆盖窗口。ready 表示流水线就绪，只有相应 valid/type 才表示某次边沿有效。

候选模块5级流水，按翻转后的码到32的距离排序，等距优先90°、180°、270°、下一周期0°。sel_index=0/1/2/3严格对应上述顺序。同极性相邻帧去重，非相邻重复保留并置 repeat_error。混合极性冲突会丢弃该帧。

locate 第1级锁存候选、下降沿以64-code翻转；第2级中测500/1000/1500/2000 ps、tap×10、捕获**当前** coarse_counter；第3级计算 coarse×2000 与 mid-fine；第4级合成；第5级模回卷输出。粗时间不是采样当拍的绝对时间，会包含前端和候选流水线的共同整数周期偏移。共同物理时间基准必须通过独立校准批次的时钟/复位与真值建立，不能拿仿真输出时刻直接当输入时间戳。

物理正向时间戳为 coarse×2000+mid-fine。若 offset=mean(T_meas-T_true)，应从该正向时间戳减 offset；理想四相中测保持不变。拟插入点为第3级相对时间计算，补偿参数选择需在第2级与 type、coarse、fine 同步寄存，保持原5级 valid 延迟。必须用独立算术测试覆盖signed与回卷，并逐拍比对关闭补偿和快照原模块。

merge 缓存最近上升沿，下降沿相减，负差加一个回卷周期。重复上升沿替换缓存并报1；孤立下降沿报2；范围错误报3并清缓存。只能识别小于一个回卷周期的脉宽，多次回卷不可辨识。repeat_error 未被 locate 使用，polarity_conflict 只门控有效边沿；候选异常未接入独立错误 FIFO，这是既有可观测性缺口，测试平台需另记。

两个23×1024独立时钟Standard FIFO分别保存有效脉宽与错误事件；写500 MHz、连续读100 MHz，valid与dout对齐。满/复位忙时结果被丢弃，overflow粘滞到复位。COARSE_W=10时TIME_W=21，顶层补2位。不能用100 MHz采集500 MHz单拍valid代替FIFO读端检查。

## 约束与已知问题

参考 XPR 含五RTL、combine.xdc、clk_wiz_0/fifo_tdc_result/ila_2/ila_3及两份旧测试平台。旧测试平台含单位/信号路径陈旧说明，不直接作为本次统计接口。

combine.xdc 仅定义100 MHz输入时钟，生成时钟由IP提供；没有用户false path或multicycle，也没有PWM及复位input delay。采样FF与CARRY4固定同slice，四链实际列X26/28/30/32、Y4..19；文件头X4/6/8/10、Y60..75已过时。PWM实际管脚AF20，与注释AD23不符；dbg_hub实际接100 MHz，C_CLK_INPUT_FREQ_HZ却写300 MHz。采用原约束建立baseline，以上差异必须在签核前确认，不能静默改成猜测值。

独立构建对该文件设置 `USED_IN_SYNTHESIS=false`、`PROCESSING_ORDER=LATE`，遵循其文件头“仅实现阶段”的说明，避免合成阶段执行布局及调试核命令；参考XPR实际将其同时用于综合和实现。因此本次是同RTL、同实现约束的新基线，并非旧工程运行的逐位复刻。该差异须保留在复现与版本记录中，补偿版使用相同设置；没有为宣称通过而添加时序例外或放宽500 MHz约束。

历史同源码工程2026-10-27的路由报告已有WNS=-0.166 ns、TNS=-0.644 ns、8个setup失败端点，hold最小+0.044 ns；这只是历史参考，不作为本次新实现结论。其2个输入未设延迟。新的500 MHz与跨相位时序须用本次报告复核；补偿无法修复真实setup/hold或漏沿。

## ATC 协议证据边界

现有旧激励仅有5/95/95/5/5/95前导序列和随机占空比，另有1 MHz载波、10 kHz调制的信号源实测；均不足以确定ATC bank帧头顺序、通道采样关系与真实SPWM协议。16×(64+2)=1056来自本次需求。暂定帧激励必须单独标记为协议假设并集中配置，不能声称验证真实ATC协议。

## 已完成的补偿RTL

活动工程仅修改顶层和locate，正式归档副本位于本任务`rtl/`。顶层传递ENABLE_SKEW_COMP与8个18位signed参数；locate在Stage2寄存与同一index/type对应的偏移，Stage3执行mid-fine-offset。相对时间扩为19位，合并算术至少20位，原5级valid/type流水完全保留。开关0使用独立generate旁路，不依赖零参数；开关1且参数0也分别与原始模块逐拍比对通过。

COARSE_W=2及10各5044次有效单元检查通过。原始完整RTL回归与补偿旁路完整回归均覆盖3512脉冲；相位调度修正后又执行独立v2回归，结果均为3512脉宽、7024时间戳、业务错误0、FIFO序列一致。这些仅为明确的理想原语功能模型结果，不是实现后精度数据。
