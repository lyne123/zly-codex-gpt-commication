# Codex 任务：XC7K325T 四相 FPGA-TDC 固定延迟补偿与实现后仿真验证

## 一、项目背景

当前工程使用 Xilinx Kintex-7 XC7K325T-FFG900-2 FPGA，实现了一套四相 500 MHz、四条独立 TDL 的 PWM 连续时间测量系统。

系统用于测量 ATC 芯片输出的 PWM，最终根据上升沿、下降沿时间戳计算高电平脉宽，并经 FIFO 传输至 100 MHz 时钟域。

本次任务需要解决四条 TDL 之间的固定延迟差异，建立补偿前、补偿后的完整对照实验。

### 当前 RTL 文件

- `tdc_meas_top.v`：顶层、时钟、各模块连接、FIFO 和 ILA。
- `tdc_fine_layer.v`：PWM 分发、四条 TDL、细测编码及相关同步。
- `tdc_time_candicate.v`：四相候选选择。
- `tdc_time_locate.v`：粗、中、细时间合并，输出时间戳。
- `tdc_time_merge.v`：上升沿、下降沿配对，输出 PWM 脉宽。

以上文件在工程中的实际路径和名字可能存在差异，请先定位并确认，不要直接覆盖或修改其他工程。

当前关键参数：

- FPGA：XC7K325T-FFG900-2
- 主时钟：500 MHz
- 四相：0°、90°、180°、270°
- 相邻相位理想间隔：500 ps
- 粗计数单位：2000 ps
- TDL：4 条独立 CARRY4 进位链
- 当前默认：16 个 CARRY4/TDL，64 taps/TDL
- 当前换算：`TAP_PS = 10`
- 时间戳和最终脉宽单位：ps
- 输出时钟域：100 MHz

注意：以上参数以实际源码和 Vivado 工程配置为准，任何不一致之处必须先报告。

## 二、任务目标

完成以下工作：

1. 审查现有四相 TDC 的信号路径、时钟、约束、流水线和数据对齐。
2. 获取四条 TDL 在实现后的固定延迟偏差。
3. 分别确定上升沿、下降沿补偿参数，共最多 8 个参数。
4. 在不破坏原有功能的前提下加入数字补偿。
5. 保留补偿开关，可独立实现补偿前、补偿后两个版本。
6. 建立自动化仿真激励和数据分析流程。
7. 完成校准数据与验证数据分离。
8. 执行实现后网表时序仿真，并比较测量结果。
9. 生成补偿前、补偿后的脉宽 RMSE、Bias、STD 及误差分布。
10. 生成并归档两个版本的 bitstream，方便后续上板。
11. 提供完整可复现的 Tcl、仿真脚本和实验报告。

最终必须保证所有报告数据真实来自执行结果，不允许编造数据、预填测量结果或将理论计算冒充仿真结果。

## 四、第二阶段：补偿参数的获取

### 4.1 补偿目的

本次补偿针对四条 TDL 的固定测量时间偏差，而不是改变四相时钟的理想相位间隔。

500 MHz 四相时钟的理想中测偏移保持原样：

- 90°：500 ps
- 180°：1000 ps
- 270°：1500 ps
- 下一周期 0°：2000 ps

补偿只修正额外的系统性时间偏差，不能重复扣除上述理想相位间隔。

### 4.2 两类数据来源

首先获取 Vivado 实现后实际布局布线结果。

尽可能利用：

- Post-Route timing report
- Routing delay report
- Cell delay report
- Implementation netlist
- SDF delay annotation

分析各条 PWM 输入分发路径，以及与时间测量相关的时钟路径。

路径报告用于理解四相偏差来源，但不能直接假定报告中某条路径延迟差值就是最终补偿参数。

最终参数应通过已知输入边沿时间、实现后仿真测量结果和多相位统计来确定。

### 4.3 四相独立观测

建立仿真专用监测机制，记录：

- 输入边沿真实时间
- 边沿极性
- 四条 TDL 的原始 tap code
- 四条 TDL 的有效状态
- 候选通道编号
- 选中通道的时间戳
- 预期时间戳
- 测量误差

优先通过 testbench 层级引用、bind 或独立 monitor 实现。

不要为了读取调试数据而大幅修改可综合 RTL，也不要在正式 bitstream 中保留不必要的校准监测逻辑。

注意：同一个 PWM 边沿不一定在四条 TDL 中同时产生有效细测结果。必须根据实际有效窗口收集数据，不允许把无效 tap code 当作正常时间戳。

如果现有信号不足以观测每条 TDL 的测量结果，可以增加最小化的调试观测机制，但必须确认该机制是否影响布局布线以及被测延迟。

### 4.4 相位扫描

使用与 500 MHz 时钟具有已知相位关系的 PWM 激励。

扫描 PWM 边沿相对于主时钟的相位：

- 覆盖完整的 2000 ps 主时钟周期。
- 初步步长可设为 10 ps 或 20 ps。
- 对每个相位收集足够多的有效样本。
- 分别测试上升沿和下降沿。
- 记录每个通道的有效采样数量及有效相位范围。

必须避免所有有效样本只集中在某几个相位点。

### 4.5 补偿参数计算

对于每条通道、每一种极性，计算测量时间戳相对于真实边沿时间的平均偏差。

定义：

`B[i][polarity] = mean(T_meas - T_true)`

优先选择统一的输入边沿参考时间。

若采用 TDL0 作为相对参考：

`OFFSET[i][polarity] = B[i][polarity] - B[TDL0][polarity]`

这里需要特别处理：

- timestamp 回卷
- 不同相位有效窗口
- 0° 下一周期边界
- 极性差异
- 流水线整数周期偏移
- 粗时间与细时间归属

若各通道只能在不同相位范围内有效，必须先建立共同的物理时间模型或进行可辨识性分析，不得简单地对不同相位样本求均值后直接相减。

如果缺乏共同参考、导致某些参数不可辨识，必须在报告中说明，不能凭空生成补偿值。

此外，相对通道偏差只能消除四相之间的固定差异，不能自动消除所有通道共有的绝对时间偏移。上升沿和下降沿公共偏差也可能影响脉宽，需要单独分析。

分别保存：

- 4 条 TDL 的上升沿偏差
- 4 条 TDL 的下降沿偏差
- 最终采用的 8 个补偿值
- 每个参数的有效样本数量
- 平均误差、标准差、拟合残差
- 参数获取方法和适用条件

输出 `tdc_skew_calibration.csv` 和 `CALIBRATION_REPORT.md`。

校准参数必须来自独立校准数据集，不允许使用最终验证集反向优化参数。

## 五、第三阶段：补偿 RTL 设计

### 5.1 补偿使能

增加可综合参数：

`ENABLE_SKEW_COMP`

建议：

- `0`：关闭补偿
- `1`：开启补偿

关闭时必须保持与原始设计一致的功能行为和脉宽计算结果。

补偿前版本不得仅依赖未经验证的零补偿参数，应有明确的 bypass 路径。

### 5.2 补偿值定义

分别提供四条 TDL 的上升沿、下降沿补偿值。

总计 8 个独立参数。

参数要求：

- 单位：ps
- 支持正数、负数和零
- 使用明确的 signed 类型
- 位宽根据合理的补偿范围确定
- 默认值不能伪装为已经测量得到的真实补偿值

建议集中管理，避免分散在多个模块。

优先使用 Verilog-2001 兼容的设计方式，保证 Vivado 2022.2 可以综合。

### 5.3 补偿位置

优先考虑 `tdc_time_locate.v`。

当前该模块具有：

- `sel_index`
- `edge_type_q`
- `s2_mid_time`
- `s2_fine_time`
- `s3_relative`

建议在转换成 ps 后，根据通道编号和边沿极性，选择相应补偿参数。

但必须先确认实际时间戳公式的符号和物理意义，再决定补偿应当加还是减。

目标是实现：

`T_corrected = T_measured - offset`

这里 offset 的定义必须严格对应测量时间戳的正向偏差。

不能只因为公式写成 `mid_minus_fine` 就直接判断补偿符号。

### 5.4 时序优化

优先保持已有流水线结构。

如果增加补偿选择和加减法后出现 500 MHz 时序违例，可以增加必要的流水级，但必须同步调整：

- valid
- edge_type
- selected index
- coarse timestamp
- fine timestamp
- error flag

禁止只增加数据流水而没有同步控制信号。

严格检查：

- signed 扩展
- 算术位宽
- 截断
- 溢出
- 负数
- 回卷边界
- 正负补偿跨周期

不允许使用不可综合的延迟语句实现 RTL 补偿。

## 八、第六阶段：RMSE 对比分析

必须使用真实输入边沿作为 ground truth。

对每个成功配对的 PWM 周期：

`error_ps = measured_width_ps - true_width_ps`

计算：

**1. 脉宽 RMSE**

`RMSE = sqrt(mean(error_ps^2))`

**2. 脉宽 Bias**

`Bias = mean(error_ps)`

**3. 脉宽 STD**

`STD = sqrt(mean((error_ps - Bias)^2))`

**4. 最大绝对误差**

`MaxAbsError = max(abs(error_ps))`

**5. 有效测量率**

`ValidRate = valid_matched_pulses / expected_pulses`

还需要分别统计：

- 时间戳误差 RMSE
- 上升沿 Bias
- 下降沿 Bias
- 各通道有效样本数
- 各通道选择比例
- 帧头测量 RMSE
- SPWM 数据部分 RMSE
- 5% duty 测量误差
- 95% duty 测量误差
- 10 MHz 和 20 MHz 的测量误差

**重要：**

补偿前后必须使用完全相同的输入激励、真实时间参考和统计窗口。

对于正常配对的脉宽，应按事件编号一一匹配后进行逐样本对比；对于丢失或额外输出的事件，必须单独报告，不允许仅统计成功测量部分就宣称整体通过。

脉宽 RMSE 是主要评价指标，STD 为辅助指标。

不得将脉宽样本去均值后的 RMS 当作脉宽 RMSE。

如果补偿后 RMSE 没有改善，必须如实报告并分析原因，不得调整统计方法来制造改善。

## 十、第八阶段：补偿前后 bitstream 归档

必须保留两个独立版本：

**Baseline：无补偿**

`ENABLE_SKEW_COMP = 0`

**Compensated：开启补偿**

## 十一、验收条件

只有满足下面的条件，才能把任务标记为通过：

- 原始 RTL 功能没有被破坏。
- 补偿开关能够独立控制。
- 补偿参数有可追溯的计算来源。
- 8 个补偿参数具有明确的通道、极性和单位。
- 补偿前后使用相同验证激励。
- RTL 功能仿真通过。
- 实现后 SDF 仿真正常执行且关键延迟注释有效。
- 有效 PWM 测量与理论脉宽接近，且误差可量化。
- 没有未解释的重复脉宽、异常配对或 FIFO overflow。
- 没有未解决的关键 Setup/Hold 违例。
- 脉宽 RMSE、Bias、STD 已计算。
- 所有关键测试均有日志和 CSV。
- 补偿前后两个 bitstream 均成功生成。
- 所有文件能够通过脚本复现。

如果由于器件模型、IP、许可证、计算资源或测试环境限制，导致某项不能完成，应标记为 BLOCKED 或 FAIL，并写明证据和下一步解决方法。

不能把未执行的测试标记为 PASS。
